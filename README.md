# 🏡 Prime Imóveis — Plataforma Web de Venda de Imóveis

## 📌 Descrição do Projeto

O **Prime Imóveis** é uma aplicação web desenvolvida com HTML, CSS e JavaScript puro, com o objetivo de simular uma plataforma moderna de venda de imóveis.

O sistema apresenta uma interface visual agradável, responsiva e interativa, permitindo que usuários visualizem imóveis disponíveis e filtrem opções com base no preço.

---

## 🎯 Objetivos

* Criar uma interface moderna e responsiva
* Simular um catálogo de imóveis
* Implementar interação com JavaScript
* Aplicar boas práticas de desenvolvimento front-end

---

## 🛠️ Tecnologias Utilizadas

* HTML5 → Estrutura da aplicação
* CSS3 → Estilização e responsividade
* JavaScript (Vanilla) → Interatividade e lógica

---

## 📱 Responsividade

O projeto foi desenvolvido com foco em **design responsivo**, adaptando-se para diferentes tamanhos de tela:

* 📱 Celulares (até 768px)
* 📲 Tablets (769px até 1024px)
* 💻 Desktops (acima de 1024px)

Utilizando **Media Queries**, o layout se ajusta automaticamente para garantir boa usabilidade em qualquer dispositivo.

---

## ⚙️ Funcionalidades

* 🏠 Listagem dinâmica de imóveis
* 💰 Filtro por faixa de preço
* 🎯 Scroll suave até a seção de imóveis
* 📩 Simulação de envio de mensagem
* 🎨 Interface moderna com efeitos de hover
* 📱 Layout responsivo

---

## 🧠 Lógica Implementada

Os imóveis são armazenados em um array no JavaScript, contendo:

* Título
* Preço
* Imagem

A renderização dos imóveis é feita dinamicamente no DOM através da função:

```javascript
mostrarImoveis()
```

O filtro é aplicado utilizando:

```javascript
filter()
```
